== Description ==

= This free plugin is a Mailster compatibility tester =

**Mailster** itself is a **premium-only** WordPress email newsletter and email marketing plugin. It is not distributed as a free download on WordPress.org.

This listing installs a **free compatibility tester** under the `mailster` plugin slug. Use it to verify that your WordPress site and hosting environment are ready for Mailster **before** you purchase a license.

After you activate the tester, open **Mailster Tester** in the WordPress admin and run the checks. The tester reviews:

- PHP and WordPress version requirements  
- Required PHP capabilities (`DOMDocument`, `fsockopen`)  
- Memory limit recommendations  
- Whether `wp_mail()` can deliver a test message  
- Whether common SMTP-related TCP ports (25, 465, 587, 993, 2525) are reachable  

When you are ready, get the full Mailster plugin from [mailster.co](https://mailster.co/?utm_campaign=wporg&utm_source=wordpress.org&utm_medium=plugin&utm_term=Mailster+Compatibility+Tester).

= Why choose Mailster for WordPress email newsletters? =

Mailster is an easy-to-use **email newsletter plugin for WordPress**. Create, send, and track newsletter campaigns without a separate ESP account for your subscriber list—your data stays in your own WordPress database.

#### Capture subscribers and grow your list

Collect subscribers with signup forms on your website or blog. Import existing lists, manage unlimited subscribers, forms, and lists on a one-time license model (support and updates require an active license period).

#### Send posts, products, and custom content

Send your latest posts, WooCommerce products, events, or other custom post types as newsletters. The same content types can drive email automation.

#### Automate welcome series, drips, and follow-ups

Set up welcome emails, birthday campaigns, drip campaigns, follow-ups, auto-responders, and more. Mailster can run targeted journeys while you focus on your business.

#### Templates and campaign editor

Choose from more than **400 free and premium email templates**. Build campaigns quickly with Mailster’s editor, or adapt designs with Mailster’s template markup language.

#### Deliverability and sending flexibility

Send with any email provider—professional SMTP/ESP services or your own server. Use RSS-to-email to turn new posts from a feed into automated campaigns. Time zone based sending helps reach subscribers when they are most likely to open.

#### Personalization, segmentation, and insights

Use merge tags for personalized content, segment audiences with Mailster’s metrics, and track opens, clicks, location, and other campaign activity in real time. Pre-check campaigns before you send so you can fix issues early.

#### Privacy and control

Mailster is designed for GDPR-conscious setups: subscriber data is stored in your WordPress database and is not handed to a third-party list host as the primary store. Capability management lets you control which team members can do what. Developers get hooks and filters to extend Mailster.

== Installation ==

1. Upload the entire `mailster` folder to the `/wp-content/plugins/` directory, or install the zip via **Plugins → Add New → Upload Plugin**.  
2. Activate the plugin through the **Plugins** screen in WordPress.  
3. Open **Mailster Tester** in the admin menu and run the compatibility checks.  
4. Review any errors or warnings, fix hosting or WordPress issues as needed, then purchase the full Mailster plugin from [mailster.co](https://mailster.co/?utm_campaign=wporg&utm_source=wordpress.org&utm_medium=plugin&utm_term=Mailster+Compatibility+Tester) when you are ready.

== Frequently Asked Questions ==

= Is this the full Mailster newsletter plugin? =

No. This free WordPress.org plugin is a **compatibility tester** only. Mailster is premium-only and is sold at [mailster.co](https://mailster.co/?utm_campaign=wporg&utm_source=wordpress.org&utm_medium=plugin&utm_term=Mailster+Compatibility+Tester).

= What does the compatibility tester check? =

It checks PHP and WordPress versions, `DOMDocument` and `fsockopen` support, memory limits, `wp_mail()` delivery, and reachability of common email-related TCP ports.

= Do I need a Mailster license to run the tester? =

No. The tester is free. You need a Mailster license only for the full email newsletter plugin.

= Can I upgrade the tester plugin to the full Mailster plugin? =

No. WordPress.org guidelines do not allow converting this free tester into the premium plugin via an in-place update. When you upload the full Mailster ZIP from your purchase, the installer replaces the tester files in place and deactivates this plugin so Mailster can take over.

= Where do I get support for Mailster? =

Use the [Mailster knowledge base](https://kb.mailster.co/?utm_campaign=wporg&utm_source=wordpress.org&utm_medium=plugin&utm_term=Mailster+Compatibility+Tester) and [Mailster support](https://mailster.co/support/?utm_campaign=wporg&utm_source=wordpress.org&utm_medium=plugin&utm_term=Mailster+Compatibility+Tester). WordPress.org support for this listing applies to the free tester plugin.
